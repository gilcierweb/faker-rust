# faker_rust::funny_name

available since version 1.8.0.

```rust
funny_name::name() //=> "sam pull"

funny_name::two_word_name() //=> "shirley knot"

funny_name::three_word_name() //=> "carson o. gin"

funny_name::four_word_name() //=> "maude l. t. ford"

funny_name::name_with_initial() //=> "heather n. yonn"
```
